# Piano Tiles

브라우저에서 바로 실행되는 피아노 타일 게임입니다. 빌드나 설치 없이 `index.html`을 열면 됩니다(GitHub Pages로도 바로 배포됩니다).
음원 파일 없이 Web Audio로 피아노 소리를 합성합니다.

## 플레이 방법

- 내려오는 **검은 타일**만 탭/클릭하세요. 빈 칸을 누르거나 타일을 놓치면 실패합니다.
- 키보드: `D` `F` `J` `K` = 1~4번 줄, `Esc` = 메뉴, 결과 화면에서 `Enter` = 다시 하기
- **긴 타일**(가운데 선이 있는 타일)은 누르고 있으면 보너스 점수를 받습니다.
- 속도: 보통 / 빠름 / 매우 빠름. **연습 모드**를 켜면 틀려도 끝까지 진행됩니다(기록은 저장되지 않음).
- 곡의 각 파트마다 스크롤 속도가 달라집니다(예: 서주는 느리게, 코다는 빠르게).

## 곡 추가하기

1. `songs/` 폴더에 새 파일을 만듭니다(예: `songs/my-song.js`).
2. `index.html`의 곡 목록 주석 아래에 `<script src="songs/my-song.js"></script>` 한 줄을 추가합니다.

```js
PianoTiles.registerSong({
  id: 'my-song',          // 고유 ID (기록 저장용, 타일 배치 시드)
  title: '곡 제목',
  composer: '작곡가',
  difficulty: 3,          // 1~5
  sections: [
    { name: '도입', tempo: 1, notes: `C4:1 D4:1 E4/C3+G3:2 r:1` },
  ],
});
```

### 악보 표기법

| 표기 | 의미 |
| --- | --- |
| `G4:1` | G4 음, 1박 = 타일 1칸 |
| `G3+Bb3+D4:2` | 화음. 2박 이상은 긴 타일(누르고 있기) |
| `G4~Bb4~D5:1` | 타일 하나에서 순서대로 연주(빠른 음형) |
| `G4/G2+D3:1` | `/` 뒤는 왼손 반주, 타일을 칠 때 같이 울림 |
| `r:1` | 쉼표(타일 없이 비움) |
| `\|` | 마디선(가독용, 무시됨) |

음 이름은 `C D E F G A B` + `#`/`b` + 옥타브(가운데 도 = `C4`). 섹션 옵션 `tempo`는 스크롤 속도 배율, `unit`은 타일 1칸의 박 수(기본 1)입니다.

### MIDI에서 변환하기

MIDI 파일이 있으면 변환기로 곡 파일 초안을 만들 수 있습니다(Node.js 필요, 의존성 없음).

```bash
node tools/midi2chart.js 곡.mid --id my-song --title "곡 제목" --composer "작곡가" > songs/my-song.js
```

옵션: `--unit 1`(타일 1칸 길이, 이보다 짧은 음은 한 타일로 묶음), `--split 60`(이 음 미만은 왼손 반주), `--tracks 0,1`, `--tempo 1`, `--bars 16`(섹션 분할), `--max-chord 3`.
변환 결과는 초안이므로 섹션 이름·템포를 다듬어 쓰면 좋습니다.
